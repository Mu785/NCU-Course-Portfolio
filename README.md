## 三、每周提交规范

1. 每次实验完成后，把文件放进对应周目录（如 `week03/`）。
2. 提交时写清楚"做了什么"，格式：`week03: 完成数据清洗实验`。
3. 一周一次及以上提交，避免期末一次性补交（那样就失去了过程记录的意义）。

常用命令速查：

```bash
git status                          # 看看改了哪些文件
git add .                           # 把改动放进"待提交区"
git commit -m "week03: 完成数据清洗实验"   # 拍一张快照存档
git push                            # 把本地存档同步到 GitHub
```
