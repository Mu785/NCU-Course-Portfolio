借用食品微生物实验里"无菌操作台"的概念：本目录是本周实验的**独立洁净区**。

- **物理隔离**：本目录与 `week01`~`week16` 及其它目录互不干扰，不引用、不修改其它周次的文件；
- **无污染源**：目录内不含临时文件、缓存、大体积原始数据与密钥，这些已被根目录 `.gitignore` 拦截；
- **洁净基线**：目录初始化提交即基线，后续所有改动都可与基线逐行对比，随时可回滚；
- **准入规则**：只放入本周实验相关的代码、报告与数据说明，其余一律不放进本目录。
