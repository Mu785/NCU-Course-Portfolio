# 环境搭建指南（Windows 11 零基础版）

本文记录本机从零到能提交作业的完整过程，换电脑时照着做一遍即可。

## 1. 安装 Git

Git 是"给文件拍快照、留历史版本"的工具。

```powershell
winget install --id Git.Git -e --source winget
```

安装后在 PowerShell 里验证：

```powershell
git --version      # 应输出 git version 2.xx.x.windows.x
```

## 2. 配置身份（每台电脑只做一次）

```powershell
git config --global user.name  "王子轩"
git config --global user.email "你的邮箱"
```

作用：让每一次提交都署名，老师能知道是谁写的。

## 3. 常用工具

- VS Code：写代码、看 Markdown 预览
- Python：数据处理与实验脚本
- GitHub Desktop：不想敲命令时的图形界面（可选）

## 4. 本机已知网络情况

- 直连 github.com 网页端口不稳定，SSH（22 端口）可用；
- 若浏览器打不开 GitHub，可换手机热点或用 `git push` 走 SSH 通道。
